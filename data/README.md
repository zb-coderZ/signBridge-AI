# Data folder

```
data/
  raw/         <- you put downloaded datasets here (NOT included, NOT zipped)
  processed/   <- landmark files (.npz) produced by the scripts
```

Landmark files are named `<source>_<LANG>_<kind>.npz`, e.g. `asl_alphabet_ASL_static.npz`, `custom_PSL_static.npz`.
`demo_*` files are SYNTHETIC (generated by `scripts/build_demo.py`) and are never used for real training.

## Where to get each dataset

| Dataset | Language / type | Put it in | How to get it |
|---|---|---|---|
| **ASL Alphabet** | ASL, static letters (images) | `data/raw/asl_alphabet/<CLASS>/*.jpg` | Kaggle `grassknoted/asl-alphabet` (free account): `pip install kaggle` then `kaggle datasets download -d grassknoted/asl-alphabet -p data/raw/asl_alphabet --unzip`. If the zip nests `asl_alphabet_train/asl_alphabet_train/`, move the class folders up so `data/raw/asl_alphabet/A/…` exists. |
| **WLASL** (small subset) | ASL, dynamic words (videos) | `data/raw/wlasl/<gloss>/*.mp4` | https://github.com/dxli94/WLASL - use `start_kit/video_downloader.py`. Many YouTube links are dead: keep only what downloads (WLASL100 is enough). |
| **MS-ASL** (optional) | ASL, dynamic | `data/raw/msasl/<gloss>/*.mp4` | https://www.microsoft.com/en-us/download/details.aspx?id=100121 (annotation JSON; fetch/clip videos yourself, links partly dead). |
| **PSL (LUMS / CHISEL, Dynamic PSL)** | PSL, static + dynamic | `data/raw/psl/<CLASS>/*.jpg` and `data/raw/psl/dynamic/<gloss>/*.mp4` | May require contacting the dataset authors for access. **If unavailable, record your own** with `scripts/record_samples.py` (this is the intended fallback, and it also adds signers). |

## Workflow

```bash
python scripts/inspect_dataset.py --all                 # what do I have? prints download help for missing ones
python scripts/extract_landmarks.py --name asl_alphabet --max-per-class 400
python scripts/record_samples.py --lang PSL --label alif --kind static --signer zb      # your own data
python scripts/train_static.py --lang ASL
python scripts/evaluate.py
```

### Signer ids and honest evaluation
The test set must contain people the model never saw. Landmark files carry a `signer` id per sample.
* ASL Alphabet has no signer ids -> every sample is signer `unknown` -> the split falls back to a random split and the
  report is labelled `random_NOT_cross_signer`. Do not present that number as signer-independent accuracy.
* Your own recordings: use a different `--signer` name for every person (you need >= 3 signers for a signer-disjoint split).
* If file names encode the signer, pass `--signer-regex` to `extract_landmarks.py`.
