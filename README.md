# SignBridge AI

SignBridge AI recognises **24 static ASL letters** from the real Sign Language
MNIST dataset and returns text and offline speech. It supports image upload,
video upload, and live webcam input.

The project uses a small augmented CNN and a Random Forest baseline. It also
includes PCA, t-SNE, K-means clustering, pixel importance, outlier detection,
confusion analysis, and a separate webcam evaluation workflow.

## Important limitation

Sign Language MNIST contains centred 28x28 cropped hand images. The official
test split may share signers with training, so its score can be optimistic.
Camera images have a domain shift and can perform worse. J and Z are not in the
dataset because they require motion. The app reports failures such as “no hand
found” instead of inventing a prediction.

## Windows setup

1. Install **Python 3.12** and enable “Add Python to PATH”.
2. Open Command Prompt in this folder:

   ```bat
   py -3.12 -m venv .venv
   .venv\Scripts\activate
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

3. Put the Kaggle files in:

   ```text
   data\raw\sign_language_mnist\sign_mnist_train.csv
   data\raw\sign_language_mnist\sign_mnist_test.csv
   ```

   Nested duplicate copies are accepted and ignored. No script downloads data.
4. Check the dataset:

   ```bat
   python scripts\inspect_dataset.py --path data\raw\sign_language_mnist
   ```

5. Train on all real rows:

   ```bat
   python scripts\train_image.py
   python scripts\data_mining.py
   ```

   For a quick pipeline check only:

   ```bat
   python scripts\train_image.py --limit 500 --epochs 1
   ```

6. Start the app:

   ```bat
   run_app.bat
   ```

The supplied `setup.bat` also creates the environment, installs requirements,
checks imports, and trains if the image model is missing.

## App tabs

- **Image**: upload a photo, crop the hand with MediaPipe Tasks, show the 28x28
  model input, and display prediction plus top three.
- **Video**: sample uploaded frames, use the stability filter, and build a
  sentence.
- **Live Webcam**: Streamlit-WebRTC webcam recognition. The import order is
  `streamlit_webrtc`, MediaPipe, then TensorFlow. Frames are returned
  immediately and inference runs on the newest frame in a background worker at
  a bounded rate, so camera video does not wait for MediaPipe. The Live model
  selector defaults to Random Forest because it is faster and scored higher on
  the official test split.
- **Data Mining Insights**: displays reports generated by
  `scripts/data_mining.py`.
- **History**: running sentence and downloadable CSV.

Speech uses `pyttsx3` on a background worker thread. If no Windows voice driver
is available, the app continues and shows a clear warning.

## Own webcam evaluation

Record examples one letter at a time:

```bat
python scripts\record_samples.py --label A --count 30
python scripts\record_samples.py --label B --count 30
```

Press **SPACE** to capture and **Q** to stop. Repeat for the letters needed.
Evaluate them separately:

```bat
python scripts\evaluate_recorded.py --path data\recorded
```

This score is a domain-shift check, not a replacement for the official test
score. It is not automatically mixed into training.

## Tests and reports

```bat
python -m pytest -q
```

Training writes real metrics to `reports\metrics.json`, model comparison to
`reports\results_table.md`, and confusion matrices to `reports\`. Mining
outputs are in `reports\mining\` and `reports\mining_summary.json`.

## Project structure

```text
app/                 Streamlit UI and WebRTC processor
core/                image loading, preprocessing, models, stability, TTS
scripts/             inspect, train, evaluate, record, and mining commands
data/raw/            user-provided Kaggle CSVs; never committed
models/trained/      trained CNN and Random Forest
reports/             real metrics, plots, and project report
tests/               focused unit and integration tests
```

## Troubleshooting

- **Dataset not found**: check both CSV names and the exact
  `data\raw\sign_language_mnist` folder.
- **No trained model**: run `python scripts\train_image.py`.
- **No hand found**: use bright lighting, one visible hand, and a plain
  background. MediaPipe needs the local `models\hand_landmarker.task`.
- **Webcam unavailable**: close other camera applications, allow browser
  permission, or use Image/Video tabs.
- **Slow CPU training**: use `--limit` and `--epochs 1` for a smoke test; the
  full run is the reported experiment.
